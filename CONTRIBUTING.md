# Contributing to LINK

First off, thank you for considering contributing to **LINK**! It's people like you that make LINK such a powerful tool for the community.

## How Can I Contribute?

### Reporting Bugs
- Check the [Issues](https://github.com/nvmax/Link/issues) to see if the bug has already been reported.
- If not, open a new issue. Include as much detail as possible, such as your environment (OS, Python version, Node version), steps to reproduce, and any error logs.

### Suggesting Enhancements
- Open a new issue and describe the feature you'd like to see.
- Explain why it would be useful to the community.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code follows the existing style (we use Prettier for JS and Black-style for Python).

## Code of Conduct

- **Be Respectful**: We are a community of creators. Treat others with kindness and respect.
- **Stay On Topic**: Keep discussions focused on the project and technical improvements.
- **Collaborate**: Help others, share knowledge, and build together.

## Questions?

If you have any questions about contributing, feel free to reach out to the maintainers or open a discussion issue.
